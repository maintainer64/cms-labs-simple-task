# Структура задания

Здесь находится само задание: описание, notebook, topology, метаданные и образ сетевых узлов. Директория `task` — нейтральный шаблон, который можно скопировать для следующей лабораторной работы. Модуль хранится обычной директорией, а не вложенным Git-репозиторием.

| Модуль | Предметный тип | Интерфейс | Проверка |
|---|---|---|---|
| [`task`](task) | `network-lab` | `jupyter-notebook` | `automatic-checker` |

Новые задания будут добавляться отдельными директориями после стабилизации этого контура.
